# Save DedSec Project

This repository automatically preserves the DedSec Project ecosystem in the Internet Archive and Wayback Machine.

## Weekly Schedule

All three groups run on **Wednesday, Friday and Sunday**, using the `Europe/Athens` timezone.

| Greece time | Archive group | Maximum job window |
|---|---|---|
| 08:00 | DedSec Project main and backup repositories | 08:00–13:00 |
| 13:50 | Main website, backup website and website source repository | 13:50–18:50 |
| 19:30 | GitHub profile, Corrupted Files Project, Pocket AI and Offline Survival Project | 19:30–23:30 |

The four projects in the final group run in parallel. The listed end times are safety limits; a successful run can finish much earlier.

## Backup Contents

For every repository, the workflow saves:

- A compressed snapshot of the complete checked-out working tree
- Git LFS working files when the repository uses Git LFS
- Checked-out submodule contents
- A complete Git bundle containing repository history and refs
- A manifest containing tracked filenames and file sizes
- SHA-256 checksums
- A Wayback Machine submission report

After the newest files are visible in Internet Archive metadata, older workflow-generated files are deleted. Wayback captures are never deleted by this workflow.
