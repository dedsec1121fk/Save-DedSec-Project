# Save DedSec Project

This private repository uses **one central GitHub Actions workflow** to archive the complete DedSec Project every day.

## Official Project Links

### Websites

- **Main website:** https://ded-sec.space/
- **Backup website:** https://ded-sec.online/

### Repositories

- **Website source repository:** https://github.com/dedsec1121fk/dedsec1121fk.github.io
- **Main project repository:** https://github.com/dedsec1121fk/DedSec
- **Backup project repository:** https://github.com/sal-scar/DedSec

## Automatic Archive

The workflow runs every day at **12:00 Europe/Athens time**. It archives both websites and all project repositories in the same workflow run.
